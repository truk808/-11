# Правила участия в проекте

Спасибо за интерес к проекту **Game of Thrones — Interactive Dashboard**!

## Цель проекта
Совместная работа над исследовательским дашбордом, который позволяет анализировать смерти персонажей и сражения во вселенной «Игры престолов».

## Как предложить изменение
1. Создайте Issue и кратко опишите задачу, проблему или предложение.
2. Обсудите решение в Issue, если задача затрагивает логику анализа или структуру данных.
3. Создайте отдельную ветку от `main`:
   - `feature/data-collection` — сбор и подготовка данных;
   - `feature/analysis` — аналитика и визуализации;
   - `feature/documentation` — документация и отчёт.
4. Вносите небольшие логически связанные изменения.
5. Используйте понятные сообщения коммитов, например `docs: add methodology wiki page`.
6. Откройте Pull Request в `main`, укажите связанный Issue и опишите изменения.
7. Дождитесь проверки (Code Review), внесите исправления и только после одобрения объедините PR.

## Требования к Pull Request
- Одна задача — один PR, насколько это возможно.
- Укажите цель, список изменений и способ проверки.
- Приложите скриншоты, если меняется интерфейс или визуализация.
- Не добавляйте исходные наборы данных с ограничениями на распространение, секреты и персональные данные.
- Проверьте, что README и другие документы не противоречат реализации.

## Стиль коммитов
Рекомендуемый формат: `тип: краткое описание`.

Примеры:
- `docs: describe dataset columns`
- `feat: add battle statistics`
- `fix: handle empty death year`
- `refactor: simplify csv parsing`

## Проверка изменений
Поскольку проект представляет собой HTML-файл, перед отправкой PR:
1. Откройте HTML в современном браузере.
2. Проверьте загрузку `character-deaths.csv`.
3. Проверьте фильтры по году, книге и дому.
4. При наличии `battles.csv` проверьте диаграмму сражений.
5. Убедитесь, что в консоли браузера нет ошибок.

## Коммуникация
Используйте Issues для конкретных задач и ошибок, Discussions — для открытых вопросов и обсуждения методологии. Будьте корректны и аргументируйте замечания.
