# Game of Thrones — Interactive Dashboard

Интерактивный дашборд для анализа смертей персонажей и сражений во вселенной сериала «Игра престолов».

Проект позволяет загружать CSV-файлы с данными, изучать статистику с помощью интерактивных графиков и таблиц, а также применять фильтры для анализа отдельных периодов, книг и домов.

## Возможности

- **Фильтрация данных:** по году смерти (AC), книге и дому персонажа.
- **Основные показатели (KPI):**
  - общее количество персонажей в датасете;
  - количество смертей с учётом выбранных фильтров;
  - средний год смерти;
  - самый смертоносный год.
- **Визуализация смертей:**
  - столбчатая диаграмма смертей по годам и домам;
  - кольцевая диаграмма доли смертей по домам;
  - график смертей по книгам и их накопительного количества;
  - тепловая карта «дом × год»;
  - таблица топ-10 домов по числу смертей;
  - диаграмма соотношения главы появления персонажа и главы его смерти.
- **Анализ сражений:** столбчатая диаграмма количества сражений по регионам при загрузке дополнительного файла `battles.csv`.
- **Адаптивный интерфейс:** поддержка светлой и тёмной цветовых схем.
- **Локальная обработка данных:** CSV-файлы обрабатываются в браузере и не отправляются на сервер.

## Используемые технологии

- HTML5
- CSS3
- JavaScript
- [Chart.js](https://www.chartjs.org/) — построение графиков и диаграмм.
- [Papa Parse](https://www.papaparse.com/) — чтение и обработка CSV-файлов.

Библиотеки Chart.js и Papa Parse подключаются через CDN.

## Запуск проекта

1. Скачайте или клонируйте репозиторий.
2. Откройте HTML-файл проекта в современном браузере.
3. Загрузите файл `character-deaths.csv` через соответствующее поле.
4. При необходимости дополнительно загрузите `battles.csv`, чтобы увидеть статистику сражений.
5. Используйте фильтры для исследования данных.

Для загрузки библиотек Chart.js и Papa Parse требуется подключение к интернету.

## Формат данных

### character-deaths.csv

Основной файл с данными о персонажах. Дашборд использует следующие столбцы:

| Столбец | Назначение |
|---|---|
| `Name` или `Character` | Имя персонажа |
| `Allegiances` | Дом или принадлежность персонажа |
| `Death Year` | Год смерти |
| `Book of Death` | Номер книги, в которой умер персонаж |
| `Death Chapter` | Глава смерти |
| `Book Intro Chapter` | Глава первого появления |

Для построения статистики смертей у записи должен быть указан год смерти.

### battles.csv (необязательно)

Дополнительный файл со сведениями о сражениях. Дашборд использует столбцы:

| Столбец | Назначение |
|---|---|
| `year` | Год сражения |
| `region` | Регион проведения сражения |

## Источник данных

Для работы дашборда используются CSV-данные о смертях персонажей (`character-deaths.csv`) и, опционально, о сражениях (`battles.csv`).

Файлы данных не включены в проект: их необходимо получить отдельно и загрузить через интерфейс дашборда. В исходном HTML в качестве места получения данных указан Kaggle.
